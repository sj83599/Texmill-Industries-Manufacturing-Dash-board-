# Texmill-Industries-Manufacturing-Dash-board-
Built a 5-page interactive dashboard for a Textile Manufacturing company from scratch — starting with messy, real-world data and ending with actionable business insights

💡 What makes this project stand out:
→ Cleaned 3,558 rows of dirty data in Power Query (duplicates, nulls, typos, mixed dates)
→ Built Star Schema model with 22+ DAX measures
→ Used advanced time intelligence — YoY Growth, Rolling Averages, YTD
→ Tracked OEE, Defect Rate, Inventory Turnover & Revenue across 5 pages
→ Applied Pareto Analysis to identify top defect types
→ Dynamic conditional formatting with traffic light KPIs

Every number on this dashboard tells a story — and I built the system to tell it.
